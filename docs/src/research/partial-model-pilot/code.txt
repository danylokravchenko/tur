Implement a function that merges two sorted lists of integers. Keep duplicates and return the result in ascending order. The input lists must remain unchanged.

def merge_sorted(left, right):
    result = []
    i = 0
    j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result

For the inputs [1, 3, 3] and [2, 3, 8], the expected result is [1, 2, 3, 3, 3, 8]. Each iteration advances exactly one input position. The running time is linear in the combined input length. The output needs one slot for each input element. Empty inputs require no special branch because extending by an empty suffix has no effect.
