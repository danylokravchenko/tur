# Larger models within a fixed memory budget

Explore bounded SSD-backed expert loading for MoE models that exceed unified memory, and calibrated weight formats below Q4K for larger dense models. MoE routing touches only selected experts per token, so a resident cache can avoid reading most weights from disk. Dense models read almost all weights each pass, making smaller resident weights the stronger initial candidate there. These are unmeasured proposals for Tur and complement the [partial-model initiative](partial-model-initiative.md) by establishing a baseline that retains access to every expert before evaluating pruning.

[Strata's Metal expert-stream design](https://github.com/Niko1221/Strata/blob/46c152a1310f77cd2f0ce2c7cd213962df14fe83/metal/src/engine/stream.h) provides an implementation reference: resident dense weights, a bounded expert arena, device indirection from expert IDs to slots, and demand reads with predictive prefetch. Its discrete-GPU CPU/VRAM split offers no extra physical memory on Apple Silicon; Tur should keep inference on Metal and use the CPU for bounded I/O and cache management.

- Add runtime expert residency. Tur currently packs experts incrementally at load time but uploads complete banks. Extend the existing `MemoryPlan` and `DeviceBudget` to account for resident weights, expert slots, metadata and staging. Fetch the original packed expert on a miss, preserving routing and numerical contracts. Keep slots owned until both outstanding reads and GPU consumers finish; cancellation and I/O failures must drain their work before reuse.
- Store each expert's gate/up and down blocks together so a miss needs one contiguous read. Strata's [expert artifact tool](https://github.com/Niko1221/Strata/blob/46c152a1310f77cd2f0ce2c7cd213962df14fe83/metal/tools/stream_experts.py) illustrates the layout. Preserve Tur's artifact validation and atomic publication. Start with demand loading, then test routing-profile warmup and next-layer prediction with bounded queues, demand-read priority and measurements of useful prefetch bytes.
- Evaluate one calibrated weight format below Q4K, with higher precision for sensitive components. Strata's [quantization study](https://github.com/Niko1221/Strata/blob/46c152a1310f77cd2f0ce2c7cd213962df14fe83/docs/QUANTS.md) shows why fit, kernel cost and quality need separate gates. Measure decode, batched verification and prefill; lower-bit weight experiments do not reopen the rejected 4-bit K/V policy without new evidence.
- Fetch sparsely accessed lookup rows through a bounded cache. Strata's [n-gram reader](https://github.com/Niko1221/Strata/blob/46c152a1310f77cd2f0ce2c7cd213962df14fe83/include/strata/ngram/ple_reader.hpp) issues reads early and deduplicates pages during prefill. Flash-Next needs its own n-gram semantics; Gemma E2B's 4.4 GiB PLE table is a separate candidate for the same storage approach, subject to row-access latency measurements.
- Include I/O wait in scheduling and speculation costs. Concurrent requests and speculative positions touch a larger union of experts, while prefill can evict experts needed by active decodes. Compare chained drafts submitted together against spending their weight and boundary-state memory on more expert slots. Tur already gates speculation by measured profitability; MoE MTP remains open work.
- Bound the whole physical footprint, including host allocations, staging and file cache, without double-counting shared buffers. A mapped file alone supplies no residency cap. Measure memory pressure during startup, sustained serving and idle periods before adopting Strata's platform-specific residency or wiring policies.

Start by validating the existing Qwen3.6-35B MoE checkpoint on a Mac that fits it and collecting routing traces. Replay cache policies offline, implement demand loading, then add prefetch and speculation only where they improve measured results. Through `just bench`, compare resident and offloaded execution at identical precision, cold and warm caches, 1/2/4/8 concurrent requests, and mixed prefill/decode traffic. Record quality, time to first token, p50/p95 token gaps, throughput, SSD bytes per token, cache misses and peak physical memory; include cancellation and I/O failure checks.

Strata's [Qwen Mac measurements](https://github.com/Niko1221/Strata/blob/46c152a1310f77cd2f0ce2c7cd213962df14fe83/docs/MAC.md) cover a Metal engine that serves one request at a time, so they do not establish Tur's concurrent-serving performance. Flash-Next also needs separate architecture conformance: Tur's router currently caps experts at 256 per layer, while Flash-Next uses 512, and QSA, gated residuals and n-gram handling remain prerequisites.
